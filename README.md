# 🔐 Multi-Stage Cipher Lab (Caesar & Vigenère)

Aplikasi berbasis web sederhana untuk mempelajari proses enkripsi **Caesar Cipher** dan **Vigenère Cipher** secara berantai. Dibangun menggunakan **Python** dan **Streamlit**.

## ✨ Fitur Utama
- **Chaining Encryption:** Hasil dari Caesar Cipher otomatis menjadi input untuk Vigenère Cipher.
- **Step-by-Step Logic:** Menampilkan detail pergeseran setiap huruf (edukatif).
- **Responsive UI:** Tampilan berdampingan (side-by-side) untuk memudahkan perbandingan.
- **Real-time Processing:** Hasil langsung muncul saat input atau key diubah.
